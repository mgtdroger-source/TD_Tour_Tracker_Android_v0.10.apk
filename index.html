TD Tour Tracker Android

TD Tour · Android installation
TD Tour Tracker is installed directly from this page rather than through Google Play.
  1. Tap Download Tour Tracker below.
  2. When the APK has downloaded, open the downloaded file.
  3. If Android shows “App blocked to protect your device”, select More and then continue with the installation.
  4. Open Tour Tracker and allow Location when asked.
  5. When Background GPS setup appears, open the phone settings and set Tour Tracker battery use to No restrictions.
  6. Return to Tour Tracker. Future Tour configuration links will load the Tour into the installed app.
Android wording can vary slightly by phone manufacturer and Android version.
