TD Tour Tracker Android

TD Tour · Android installation
This one Tour link carries the Tour configuration. If Tour Tracker is already installed, open it below. If not, install it first, then return to this page and open it for the Tour.
  1. If Tour Tracker is already installed, tap Open Tour Tracker for this Tour.
  2. If it is not installed, tap Install Tour Tracker v0.08 and complete the installation.
  3. Return to this Tour page and tap Open Tour Tracker for this Tour.
  4. Allow Location when asked. When Background GPS setup appears, set Tour Tracker battery use to No restrictions.
  5. Once Tour Tracker is configured and open, this web page can be closed.
Android wording can vary slightly by phone manufacturer and Android version.
